# Jetan Piece Artwork

The piece sprites and source files in this directory are derived from
[`Jetan Board.svg`](https://commons.wikimedia.org/wiki/File:Jetan_Board.svg) by
Wikimedia Commons user
[`Ninjatacoshell`](https://commons.wikimedia.org/wiki/User:Ninjatacoshell).

The original and these cropped, background-removed derivatives are licensed
under the [Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)
License](https://creativecommons.org/licenses/by-sa/3.0/).

Changes made for this project: each piece was cropped from its starting square,
the connected square background was made transparent, and the result was scaled
and centered in a 56×56 pixel PNG. The reproducible transformation is in
`generate_piece_assets.py`.
